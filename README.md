# Netflix Clone 🎬

A responsive Netflix landing page clone built using HTML and CSS.

## 🌐 Live Demo

[View Live Website](https://ishanlodh0001.github.io/Netflix-Clone-/)

## 📌 About the Project

This project is a frontend clone of the Netflix India landing page. It was created for learning and practicing web development concepts such as HTML structure, CSS styling, responsive design, layouts, and media integration.

## ✨ Features

- Netflix-style landing page
- Responsive design for different screen sizes
- Netflix-style hero section
- Background movie artwork
- Navigation bar with:
  - Netflix logo
  - Language button
  - Sign In button
- Email input and Get Started button
- TV and device sections
- Download shows section
- Kids profile section
- FAQ section
- Footer with useful links
- Video previews in device/TV sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- HTML5 Video
- Responsive CSS / Media Queries
